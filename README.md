# NNDL Lab (Experiments 8-15)
LeNet, ResNet detection, VGG16 transfer learning, char-RNN, BiLSTM NER, NMT with attention, RBM scene case study, GAN. TensorFlow/Keras Jupyter notebooks.

Download one experiment in a Jupyter terminal:
    curl -sL https://raw.githubusercontent.com/Subodh584/nndl-lab/main/get.sh -o get.sh && bash get.sh exp8

No curl? Use Python:
    python -c "import urllib.request as u; u.urlretrieve('https://raw.githubusercontent.com/Subodh584/nndl-lab/main/get.py','get.py')"
    python get.py exp8
